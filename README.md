# NetFree Yemen MVP

Functional Flutter MVP:
- Detects current connectivity type (Wi-Fi/mobile/offline)
- Runs Cloudflare-based latency, download, and upload tests
- Opens Android APN settings (device-dependent)
- Provides safe guidance for official carrier offers/public Wi-Fi

## Build on GitHub from a phone
1. Create a GitHub repository `NetFree-Yemen`.
2. Upload all project contents to the repository root, including hidden `.github` folder.
3. Go to Actions and run **Build NetFree Yemen APK**.
4. Download the `NetFree-Yemen-APK` artifact from the successful workflow.
5. Extract the artifact ZIP and install `app-release.apk`.

The speed test uses data. Carrier-specific free internet is not included; the app does not bypass billing or network restrictions.
